# Kodify Enterprise RAG

An enterprise RAG application, built step by step in the Kodify Dev YouTube course.

## Tech stack
- .NET 10 Web API
- Angular
- Microsoft Agent Framework
- Microsoft Foundry
- Azure AI Search
- Azure Blob Storage

## Episodes
1. Welcome, live demo, tech stack and project setup
2. RAG concepts in depth
3. Azure: resource group, Microsoft Foundry and model deployments
4. Azure: AI Search and Blob Storage
5. Backend from scratch: Web API, configuration, Foundry client and the first agent
6. Knowledge ingestion: Blob Storage, historical data and the Azure AI Search indexer pipeline
7. Retrieval and answers: hybrid search, semantic ranker, grounding, citations, streaming and follow-up questions
8. Image RAG, image generation with agent tools, and the streams for the interface
